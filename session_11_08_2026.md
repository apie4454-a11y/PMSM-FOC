# Session 10-08-2026: Closed-Loop Stability Analysis — Controller Margins Verification

**Date:** 10-08-2026  
**Objective:** Linearize PMSM FOC model and verify stability margins (Phase Margin, Gain Margin) for 3 cascaded PI controllers using Bode/Nyquist/Nichols plots.

---

## Cascaded Control Architecture

```
Speed Controller (2 kHz, Ts = 5e-4 sec)
    ↓
Current Controller Id (20 kHz, Ts = 5e-5 sec)
Current Controller Iq (20 kHz, Ts = 5e-5 sec)
    ↓
Motor Plant (mechanical + electrical)
```

---

## Controller Design Method

**PI Tuning via Pole-Zero Cancellation:**
- Current controllers: Kp = L·ωc, Ki = R·ωc (ωc = 2π × 2000 rad/s, ~20 kHz update rate)
- Speed controller: Lower bandwidth (~2 kHz update, but effective loop ~200 Hz closed-loop), cascaded after current loop
- Anti-windup: Back-calculation clamping at Vdc/√3 = 29.5V

## Stability Margins: 3 Loops Analyzed

### **Loop 1: Current Controller (Id Channel)**

**Linearization Point:** Id_ref → Id_motor (loop break at feedback)

| Metric | Value | Spec | Status |
|--------|-------|------|--------|
| Phase Margin | 77.7° | > 45° | ✅ +32.7° buffer |
| Gain Margin | ~70 dB | > 6 dB | ✅ +64 dB buffer |
| Bandwidth | 1.29e+04 rad/s | ~2 kHz | ✅ Matches design |
| Closed-loop stable? | Yes | — | ✅ Verified |

**What changed:** Pole-zero cancellation tuning moved poles from right-half plane (unstable) → left-half plane (stable at ~1.29e+04 rad/s).

**Evidence:** Bode plot shows phase rolls off smoothly; Nyquist curve far from -1+j0; Nichols chart stays in stable region.

### **Loop 3: Speed Controller (rpm tracking)**

**Linearization Point:** rpm_ref → rpm_actual (loop break at feedback; inner current loop remains closed)

| Metric | Value | Spec | Status |
|--------|-------|------|--------|
| Phase Margin | 95.2° | > 45° | ✅ +50.2° buffer |
| Gain Margin | > 6 dB | > 6 dB | ✅ Exceeds spec |
| Bandwidth | 131 rad/s | ~200 Hz (20 Hz effective) | ✅ Cascaded design |
| Delay Margin | 0.0127 sec | — | ✅ Excellent timing tolerance |
| Closed-loop stable? | Yes | — | ✅ Verified |

**What changed:** Speed PI tuning created outer loop with 10×–100× lower bandwidth than current loop → clean cascade decoupling.

**Evidence:** Nyquist plot forms large circle around origin, far from -1+j0; Nichols chart shows smooth bell curve shape typical of well-damped system.
