2. Sampling id iq at carrier peak - Simulation
-> Carrier peak theoretically is 1
-> Sampling at peak is implemented by finding peak and when peak, use a trigger susystem to sample and hold iq , id. Same trigger can be used to trigger the current controller subsystems as well, ensuring harware ISR kind of behaviour in MATLAB

Finding peak
-> Actual peak is a float number, less thatn 1.0
-> Carrier is symmetric
-> freq is 20kHz
-> half cycle is 25 micro sec
-> means it has a detla in amplitude of 1-(-1) = 2 in 25 micro sec
-> matlab step size is 5e-7
-> means per step in matlab, the carrier changes 0.04 in amplitude

so peak is found by NOT Carrier = 1, 
but carrier > 1- delta, where delta is less than 0.04

in simulation, peak is found by
carrier > 0.99

Changes made to current controller block
Te_ref inport sample time was 5e-4. changed to -1
id and iq PI controller sample time was 5e-5. changed to -1
